# Map styles

`liberty.json` (day) and `fiord.json` (night) are the OpenFreeMap styles
(https://github.com/hyperknot/openfreemap-styles), used under their original licences, which are
listed in that repository. RoadPulse changes: sources point at the locally built tiles, the
shaded-relief raster layer is removed, and all labels use Noto Sans Regular.
Map data © OpenStreetMap contributors (ODbL); OpenMapTiles schema.
The symbols in `sprites/` are downloaded by `setup-offline-maps.ps1` and not stored in git.
